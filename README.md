### 👤 Minha Filosofia e Abordagem

Eu não defino meu perfil com títulos teóricos: **deixo meu trabalho diário e os resultados dos meus projetos falarem por mim.** Atualmente estou concluindo um programa de Ciência de Dados e o uso como porta de entrada para a indústria de tecnologia. Meu objetivo real, porém, é mais específico:
**engenharia de dados e arquitetura de soluções**, construindo pipelines prontos para produção, trabalhando com Azure e Databricks e, com o tempo, evoluindo para arquiteto de soluções.

Minha formação em Engenharia Industrial me dá uma visão estrutural e de otimização de processos que aplico diretamente aos dados: como a informação flui, onde se formam os gargalos e como projetar sistemas que se sustentam no uso real, e não apenas parecem corretos no papel.
